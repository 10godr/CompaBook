# Knowledge Hub

Mi app personal para aprender: guardo un concepto (escrito o dictado con Siri), una IA me arma una ficha de estudio con explicación, ejemplos, videos en español y preguntas de repaso, y yo programo cuándo estudiarlo con notificaciones en el celular.

Todavía está en fase de diseño, sin código.

## Stack

- **Frontend:** React + TypeScript + Vite (PWA)
- **Backend:** Python + FastAPI
- **Base de datos y auth:** Supabase
- **IA:** Gemini API
- **Videos:** YouTube Data API
- **Hosting:** Vercel; tareas programadas con Supabase `pg_cron`
